# EE_SIM_NextGen

Simulatore di circuiti elettronici open source, nel browser, con l'immediatezza di EveryCircuit e l'accuratezza di SPICE.

- **Interfaccia:** React + TypeScript + Vite
- **Motore real-time:** MNA con Newton-Raphson, algoritmi ispirati a CircuitJS1 e riscritti da zero in TypeScript
- **Motore di precisione:** ngspice compilato in WebAssembly
- **Licenza:** GPL v3
